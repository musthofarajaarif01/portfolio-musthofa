PORTOFOLIO A. MUSTHOFA RAJA ARIF

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder portfolio_musthofa.
3. Klik dua kali file index.html, atau buka folder menggunakan Visual Studio Code.
4. Jika memakai VS Code, jalankan index.html dengan ekstensi Live Server (opsional).

CATATAN
- Website ini statis, dibuat menggunakan HTML, CSS, dan JavaScript murni.
- Tidak membutuhkan database maupun proses instalasi framework.
- Pastikan folder assets, css, dan js tetap berada di samping index.html.
- Font Google membutuhkan koneksi internet; website tetap dapat dibuka tanpa font tersebut.
